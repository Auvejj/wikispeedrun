# Wiki Sprint

Browserová hra, ve které se pomocí odkazů na Wikipedii dostaneš ze startovního článku do cíle.

## Publikování na GitHub Pages

Projekt je nastavený pro GitHub repozitář s názvem `wikispeedrun`.

1. Vytvoř na GitHubu nový veřejný repozitář `wikispeedrun`.
2. Nahraj do něj soubory tohoto projektu včetně skrytých cest `.github/workflows/deploy.yml` a `src/`.
3. V repozitáři otevři **Settings → Pages** a jako zdroj vyber **GitHub Actions**.
4. Po nahrání souborů otevři záložku **Actions** a počkej na dokončení workflow **Deploy to GitHub Pages**.
5. Hra bude dostupná na `https://Auvejj.github.io/wikispeedrun/`.

Každá další změna nahraná do větve `main` se automaticky znovu publikuje.
